# Task Manager

A simple and responsive Task Manager Web Application built using React.js.

## Features

- Add tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Filter tasks
- LocalStorage
- Responsive design

## Tech Stack

- HTML5
- CSS3
- JavaScript ES6+
- React.js
- React Hooks
- Vite

## Installation

Clone the repository:

git clone YOUR_GITHUB_URL

Go to the project folder:

cd task-manager

Install dependencies:

npm install

Start the application:

npm start

## How It Works

Tasks are stored in React state and saved in browser LocalStorage.
